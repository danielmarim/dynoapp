# Dyno Maker

Nicho do ecossistema Dyno. Ainda sem código neste repositório.

- **Público e objetivo:** Microempreendedores e negócios de impressão 3D.
- **Situação:** Desenvolvimento mencionado

## O que já se sabe

- Nicho próprio a partir do Dyno Business: o workflow `Dyno Business | WhatsApp (grupos dos negócios)` já tem a tag `dyno-maker` no n8n.
- Decisão pendente de nome: "Dyno Maker" × "3D Felps Maker".
- Documentos no projeto: pasta `dyno-maker/`.

## Quando ganhar código

Seguir o desenho dos outros produtos: `docs/` para escopo e notas, `n8n/workflows/` para o backup dos workflows
(com um prefixo próprio no n8n, ex.: `Dyno Maker | …`, e uma linha em `PRODUTOS` no
[`limpar_export.py`](../plataforma/n8n/limpar_export.py)). O que for comum a outros produtos vai para
[`../plataforma/`](../plataforma/) ou para o core do [Dyno Business](../dyno-business/).
